# StoryArc V2.0 - 时间推理增强模块

**日期**: 2025-12-17
**提交**: `b0627bf`
**分支**: `fix`

---

## 背景问题

在 LoCoMo 基准测试中，BMAM V1 的 Temporal（时间推理）类别准确率只有 **35.1%**，远低于 MemOS 的 **73.2%**。

### 根因分析

1. **91% 的记忆使用 `context` 方法** - 直接使用对话日期作为事件时间
2. **只有 9% 使用 `relative` 方法** - 正确计算 "yesterday + 08 May → 07 May"
3. **[Event] 摘要丢失时间信息** - 聚合时没有保留原始事件时间

---

## 解决方案: StoryArc 时间线模块

### 架构设计

```
┌─────────────────────────────────────────────────┐
│              Story Arc Manager                   │
├─────────────────────────────────────────────────┤
│  Timeline Index                                  │
│  ├─ 2023-05-07: [event1, event2]                │
│  ├─ 2023-05-08: [event3]                        │
│  └─ 2023-07-05: [event4, event5]                │
├─────────────────────────────────────────────────┤
│  Entity-Event Map                                │
│  ├─ Caroline: [(07 May, LGBTQ), (05 Jul, museum)]│
│  └─ Melanie:  [(08 May, camping), ...]          │
├─────────────────────────────────────────────────┤
│  Query Interface                                 │
│  ├─ query_event_time(entity, event_type)        │
│  ├─ calculate_duration(entity, reference)       │
│  └─ get_events_in_range(start, end)             │
└─────────────────────────────────────────────────┘
```

### 三层时间推理策略

```python
async def _temporal_reasoning(self, query, memories):
    # 1. Metadata 查询 - 从记忆的 event_time 元数据
    result = await self._try_metadata_based_reasoning(...)
    if result: return result

    # 2. StoryArc 查询 - 从时间线索引直接查找 (V2.0 新增)
    result = await self._try_story_arc_reasoning(query)
    if result: return result

    # 3. LLM 推理 - 复杂问题的最后回退
    return await self._llm_temporal_reasoning(...)
```

### 高置信度过滤

只有以下提取方法的事件时间会进入 StoryArc：
- `relative` - 从相对时间计算 (e.g., "yesterday" + 08 May → 07 May)
- `absolute` - 明确的绝对日期 (e.g., "On May 7, 2023")
- `explicit` - 显式指定的时间
- `metadata` - 从元数据获取
- `inherited` - 从原始对话继承

排除的方法：
- `context` - 使用对话日期作为近似值（低置信度）
- `fallback` - 无法确定时间

## 使用方法

### 迁移历史数据

```bash
python scripts/migrate_to_story_arc.py
```

### 程序中使用

```python
from src.memory.story_arc import get_story_arc_manager

story_arc = get_story_arc_manager()

# 查询事件时间
result = await story_arc.query_event_time(
    entity="Caroline",
    event_keywords=["museum", "visit"]
)
# {'formatted_date': '5 July 2023', 'confidence': 0.95, ...}

# 计算时间跨度
result = await story_arc.calculate_duration(
    entity="Caroline",
    reference="friends"
)
# {'duration': '4 years', 'start_date': date(2019, 5, 8), ...}
```
