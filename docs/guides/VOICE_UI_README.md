# 🎤 类脑智能体语音交互系统

基于您的类脑记忆系统的持续语音交互界面，类似GPT的语音模式。

## 🚀 快速开始

### 1. 安装依赖
```bash
python install_voice_dependencies.py
```

### 2. 启动系统
```bash
# 图形界面版本（推荐）
python start_voice_ui.py

# 或者命令行版本
python voice_cli.py
```

## ✨ 功能特性

### 🎯 核心功能
- **持续语音交互** - 类似GPT语音模式的连续对话
- **智能语音激活** - 自动检测语音开始和结束
- **高质量识别** - 基于OpenAI Whisper的中文语音识别
- **自然语音合成** - 支持中文文本转语音
- **实时可视化** - 直观的状态指示器和对话历史

### 🧠 智能特性
- **完整集成** - 直接连接您的12智能体类脑记忆系统
- **记忆管理** - 自动存储和检索对话记忆
- **情感感知** - 压力和威胁检测
- **个性化** - 基于神经可塑性的自适应学习

## 📋 系统要求

### 硬件要求
- **麦克风** - 用于语音输入
- **扬声器/耳机** - 用于语音输出
- **网络连接** - OpenAI API调用

### 软件依赖
- Python 3.8+
- sounddevice (音频处理)
- webrtcvad (语音激活检测)
- pyttsx3 (文本转语音)
- openai (语音识别API)
- tkinter (GUI界面)

### API配置
- ✅ **已自动配置** - 系统会自动从 `.env` 文件加载您的OpenAI API密钥

## 🎮 使用方法

### 图形界面版本
1. 运行 `python start_voice_ui.py`
2. 点击"启动"按钮
3. 对着麦克风说话
4. 观察状态指示器：
   - 🟢 监听中 - 系统正在监听
   - 🟢 处理中 - 正在识别和处理
   - 🟢 回复中 - 正在语音回复

### 命令行版本
1. 运行 `python voice_cli.py`
2. 直接对着麦克风说话
3. 系统自动处理并回复
4. 按 Ctrl+C 退出

## 🔧 技术架构

### 音频处理流程
```
麦克风输入 → VAD检测 → 语音缓冲 → Whisper识别 → 类脑系统处理 → TTS合成 → 扬声器输出
```

### 核心组件
- **VoiceActivityDetector** - WebRTC VAD语音激活检测
- **ContinuousVoiceUI** - 持续语音交互主类
- **VoiceUIWindow** - Tkinter图形界面
- **BrainInspiredCoordinator** - 您的类脑记忆系统

## ⚙️ 高级配置

### 音频参数
- 采样率: 16kHz
- 声道: 单声道
- VAD灵敏度: 中等
- 静音检测: 20帧阈值

### 系统参数
- 音频块大小: 30ms
- 处理延迟: <200ms
- 支持语言: 中文为主，支持多语言

## 🎯 使用技巧

### 获得最佳效果
1. **环境要求**
   - 安静的环境，减少背景噪音
   - 麦克风距离嘴巴20-30cm
   - 说话清晰，语速适中

2. **交互方式**
   - 自然说话，无需特殊指令
   - 说完后停顿1-2秒等待处理
   - 可以打断系统回复

3. **功能使用**
   - 可以要求系统"记住"信息
   - 询问之前的对话内容
   - 进行复杂的多轮对话

## 🐛 故障排除

### 常见问题

1. **麦克风无法识别**
   ```bash
   # 检查音频设备
   python -c "import sounddevice; print(sounddevice.query_devices())"
   ```

2. **语音识别失败**
   - 检查网络连接
   - 确认OpenAI API密钥有效
   - 确保说话清晰

3. **界面无响应**
   - 重启程序
   - 检查依赖是否完整安装

4. **语音合成失败**
   - 检查系统TTS引擎
   - macOS: 确保系统语音设置正确
   - Windows: 检查SAPI语音引擎

### 调试模式
```bash
# 使用命令行版本进行调试
python voice_cli.py
```
